# Yash Store — E-Commerce Front-End Learning Project

A responsive storefront interface built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive storefront layout
- Product cards with product photography
- Search and category filtering
- Add-to-bag interaction
- Quantity controls and item removal
- Subtotal calculation
- Cart persistence with browser localStorage
- Demo newsletter and checkout interactions

## Run locally
1. Download and extract this project.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Files
- `index.html` — page structure and content
- `style.css` — layout, typography, colours and responsive styles
- `script.js` — product data, search, filters and cart behaviour

## Important project scope
This is a front-end learning project. It does not include a backend, user authentication, order management, email subscription service or payment gateway. Product photos and web fonts load from external services, so an internet connection is needed for those assets.
